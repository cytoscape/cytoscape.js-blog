Cytoscape.js 3.30.0 has been released.  This version brings with it several notable, new features:

- Improved Node.js support ([#3230](https://github.com/cytoscape/cytoscape.js/issues/3230)), as contributed by [rettgerst](https://github.com/rettgerst).
- Styling edge lines with line-outline properties (border) ([#3243](https://github.com/cytoscape/cytoscape.js/issues/3243)), as contributed by [xkdgo](https://github.com/xkdgo).

The full list of changes can be found in the [3.30.0 milestone on GitHub](https://github.com/cytoscape/cytoscape.js/milestone/250?closed=1).
