Cytoscape.js 3.33.0 has been released.  This version brings with it several notable, new features:

- Enable line selection when start or end point is within box selection ([#3359](https://github.com/cytoscape/cytoscape.js/issues/3359)).
- For breadthfirst layout, enable 'left-right', 'right-left', and 'bottom-top' tree direction in addition to the default 'top-bottom' ([#3369](https://github.com/cytoscape/cytoscape.js/issues/3369)).
- Add support for circular text background shape ([#3385](https://github.com/cytoscape/cytoscape.js/issues/3385)). 

The full list of changes can be found in the [3.33.0 milestone on GitHub](https://github.com/cytoscape/cytoscape.js/milestone/264?closed=1).
