Cytoscape.js 3.29.0 has been released.  This version brings with it several notable, new features:

- New edge type: smooth-segments ([#3201](https://github.com/cytoscape/cytoscape.js/issues/3201)), as contributed by [Eliot Ragueneau](https://github.com/EliotRagueneau).
- Edge line properties for node borders ([#3199](https://github.com/cytoscape/cytoscape.js/issues/3199)), as contributed by [Eliot Ragueneau](https://github.com/EliotRagueneau).
- border-radius property for node shapes with rounded corners ([#3198](https://github.com/cytoscape/cytoscape.js/issues/3198)), as contributed by [Eliot Ragueneau](https://github.com/EliotRagueneau).
- ESM support ([#3217](https://github.com/cytoscape/cytoscape.js/issues/3217)), contributed by [ayjayt](https://github.com/ayjayt).

The full list of changes can be found in the [3.29.0 milestone on GitHub](https://github.com/cytoscape/cytoscape.js/issues?q=is%3Aopen+is%3Aissue+milestone%3A3.29.0).
