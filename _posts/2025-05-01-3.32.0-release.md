Cytoscape.js 3.32.0 has been released.  This version brings with it several notable, new features:

- Ring charts ([#3340](https://github.com/cytoscape/cytoscape.js/issues/3340)).
- Stripe charts ([#3341](https://github.com/cytoscape/cytoscape.js/issues/3341)).

The full list of changes can be found in the [3.32.0 milestone on GitHub](https://github.com/cytoscape/cytoscape.js/milestone/258?closed=1).
